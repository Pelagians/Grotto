# Sports Source Probe

`grotto-sports-source-probe` retrieves a bounded list of public sports sources. The job fixes source classes, hosts, deadline, request count, and response size. Each URL fails independently.

Output is raw evidence and candidate claim material only. Nyra and Sports Edge Lab remain responsible for claim normalization and provenance. Paths: `/work/input`, `/work/raw`, `/work/output`, `/work/logs`. Ports: none. Canary: `grotto-sports-source-probe canary`.
